Met4J is an open-source Java library dedicated to the structural analysis of metabolic networks. It also offers many features to edit, convert and parse SBML files, and comes with a toolbox gathering command-line applications for several analyses relevant to metabolism-related research.

Modules

met4j-core
The key module, with the core classes and data structures for handling metabolic networks (networks, metabolites, reactions, genes, proteins, enzymes, pathways, compartments).
met4j-io
Reading and writing metabolic networks in several formats: SBML, with its FBC, Groups, Miriam annotation and Notes plugins, KEGG, tabulated files and matrices.
met4j-graph
Graph-based topological analysis of metabolic networks: compound, reaction and bipartite graphs, load points, choke points, scope and precursor networks, edge weighting (degree, chemical similarity) and export to Cytoscape (GML, XGMML).
met4j-chemUtils
Chemical information associated with metabolites: chemical formula parsing, molecular mass computation, InChI handling and chemical similarity based on molecular fingerprints.
met4j-mapping
Mapping of omics data and attributes onto metabolic networks, fuzzy matching of entity names, and statistical tools for pathway enrichment analysis.
met4j-mathUtils
Mathematical utilities: a generic matrix interface with EJML and MTJ implementations, matrix export and similarity computations.
met4j-reconstruction
Helpers for metabolic network reconstruction, such as checking the mass balance of reactions from the chemical formulas of their metabolites.
met4j-toolbox
High-level command-line applications making the library's features accessible without coding: converters (e.g. Sbml2Graph, Tab2Sbml, Kegg2Sbml), network analysis (e.g. ChokePoint, LoadPoint, ScopeNetwork, MetaboRank) and reconstruction (e.g. SbmlCheckBalance, CreateMetaNetwork).

Source code, user documentation and examples: https://forge.inrae.fr/metexplore/met4j
